# Prospectos URBANS — prototipo móvil

La aplicación visual se encuentra en `index.html` (pendiente de incorporación al repositorio). Esta carpeta **no constituye un CRM multiusuario en producción**. El prototipo utiliza localStorage para guardar registros en cada navegador y carga OCR en el dispositivo desde Tesseract.js. Evitar recopilar información sensible de prospectos en una página pública de demostración.
